- **The release-branch equivalence test now builds the ref the workflow actually publishes** (#477). `tests/test-release-branch-461.sh` hard-coded `--ref HEAD`, while `.github/workflows/release-branch.yml` builds and publishes `$SOURCE_REF`. On a `workflow_dispatch` run with an older `ref=` input the two diverge, and the equivalence step was silently checking the wrong tree. It now reads `$SOURCE_REF` from the environment, falling back to `HEAD` for a local/manual run.
