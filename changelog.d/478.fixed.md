- **`detect_heredoc_lines()` in `tests/test-no-heredocs-459.sh` no longer confuses a read failure with a clean file** (#478). An `awk` failure (a vanished file, a permissions problem) produced the same empty string as a file that was genuinely scanned and found clean. `awk`'s own exit status is now captured separately from `grep`'s, so an unreadable file is reported distinctly instead of silently passing.
