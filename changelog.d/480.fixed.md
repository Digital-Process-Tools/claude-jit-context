- **A crashed helper process no longer truncates a committed index** (#480). On macOS 27,
  the built-in `/bin/bash` 3.2.57 can kill forked `awk` children with `Bus error: 10`
  partway through `rebuild-tsv.sh` -- not reproducible under Homebrew bash, and too rare in
  this plugin's own short test runs to ever show up there. `rebuild-tsv.sh` already
  detected one shape of that crash and reported it, but it had already truncated the REAL,
  committed `00-index.tsv` before the rebuild loop even started, so the run kept writing
  into the file a fresh clone and the hooks read as this tree's rules -- in the reporter's
  project, 7 indexes ended up empty and the largest went from 3,714 rows to 1,430.

  Every index is now built into a temp file in the same directory and swapped into place
  with a single `mv` only when that index's own build finished clean; a crashed helper
  still exits the whole rebuild non-zero, but the previously committed index for the layer
  it crashed in is left on disk, untouched, byte-identical to what it was before the run.
